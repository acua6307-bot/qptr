# qptr

Quantum physics and quantum computing work developed in R, Quarto, and Jupyter.

## Contents

This repository contains notebooks, Quarto documents, R scripts, and computational experiments developed during the `qptr` project.

## Topics

- Quantum mechanics
- Quantum computing
- Quantum information
- Quantum statistical mechanics
- R and Quarto
- Python/Jupyter notebooks
- Numerical quantum simulations

## Project structure

The repository primarily contains source documents and computational notebooks. Generated files and local reference materials are excluded through `.gitignore`.

## Reproducibility

The computational environment and required R/Python packages may vary between notebooks. Individual notebooks and Quarto documents contain the code used for the corresponding analyses and simulations.
